# Old V3 / eco archive

This archive contains historical documentation for the removed legacy Canonical V3 / `eco_*` system.

These documents are not current architecture. The current replacement path is the `ec_*` sidecar, including `ec_source_layer`. Current source facts and legacy Datacenter reporting continue to use `dc_*`.

This documentation cleanup does not remove old database migrations or tables. Runtime code and production databases are not changed by this archive.
